# 개발 확정사항

행사는 지파장 승인이 완료된 건만 등록한다. 시스템 안에서는 등록 자체가 승인 완료를 의미하므로 승인 대기·승인·반려 절차를 제공하지 않는다.

1. 웹 행사 등록 권한은 부장단과 관리자에게 있다. 텔레그램 봇 사용자는 봇에서 행사 등록·수정·삭제를 할 수 있다.
2. 봇 등록 시 24개 부서 중 행사 담당 부서를 선택한다.
3. 등록 즉시 캘린더에 표시한다. 행사 유형은 총회 행사·지파 행사·교육 행사·정기 행사·기타 행사로 시작한다.
4. 캘린더에는 부서명을 표시하고, 색상은 행사 유형별로 구분한다. 관리자는 행사 유형명과 색상을 수정할 수 있다.
5. 등록자 본인과 관리자만 행사 정보를 수정·삭제할 수 있다. 봇 사용자는 봇에서 선택한 행사에 대해 수정·삭제할 수 있다.
6. 삭제는 실제 데이터 삭제가 아닌 `삭제됨` 상태 처리다. 캘린더에서는 숨기고 삭제자·삭제 시각·변경 이력을 보존한다.
7. 행사 종료 전에는 등록자와 관리자가 행사 정보를 수정할 수 있다. 종료 후 일반 등록자는 실제 참여 인원과 아카이브만 수정할 수 있고, 나머지 항목은 관리자만 수정한다.
8. 행사 상태는 승인 상태가 아니라 행사 일시 기준 예정·진행 중·종료·삭제됨으로 표시한다.
9. 행사 등록·수정·삭제 알림은 텔레그램 접수 알림방에만 보낸다. 업무소통방 알림과 승인·반려·취소 알림은 사용하지 않는다.
10. 아카이브는 행사 종료 후 등록자 또는 관리자가 작성·수정하며, 게시글과 이미지를 함께 관리한다. 기존 첨부 제한은 유지한다.
11. 실제 참여 인원과 아카이브는 행사 종료 후 기록한다. 행사 유형·부서·기간·행사명·아카이브 검색을 제공한다.
12. 부서 비활성화 시 기존 행사와 아카이브를 보존한다.
13. 모바일은 웹 기능 안정화 후 반응형 웹/PWA부터 진행한다.
