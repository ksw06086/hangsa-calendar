# 봇 버튼 형식 복원 안내

2026-09-17 이전 DM 버튼은 `/start` 또는 `/menu`에 답장하는 메시지 아래의 `inline_keyboard`였다. 그다음 구현은 입력창 위 `reply_keyboard`를 보여주고, 선택하면 새 1시간 웹 링크를 답장했다. 현재 구현은 입력창 위 버튼을 한 번 눌러 웹을 연다.

## 1시간 권한으로 되돌리기

이전 권한은 `tickets.expires`에 `Date.now() + 3600000`을 저장하고, API에서 `expires > Date.now()`인 경우만 허용했다. 만료된 권한은 시간별 정리 작업이 삭제했다. 현재 구현의 만료 없는 키보드 권한은 `expires = NULL`로 구분하며, 기존 1시간 링크는 계속 만료된다.

모든 봇 권한을 다시 1시간으로 제한하려면 다음을 적용한다.

```js
// server.js: /api 인증에서 이전 조건으로 복원
.prepare("SELECT token FROM tickets WHERE token=? AND expires>?")
.get(ticket, Date.now())

// server.js: /start 키보드 권한 생성 시 이전 만료 시각 사용
db.prepare("INSERT INTO tickets VALUES(?,?)").run(
  token,
  Date.now() + 3600000,
);
```

이 조건을 복원하면 기존의 만료 없는 키보드 버튼도 즉시 사용할 수 없게 된다. `/start`로 새 버튼을 받아야 한다. 한 번 눌러 웹을 여는 키보드를 유지한다면 새 버튼도 1시간 뒤 만료되므로 `/start`로 갱신해야 한다.

## 두 번 누르는 키보드 방식으로 되돌리기

DM `/start` 응답의 `keyboard` 항목을 `{ text: "행사 등록" }`, `{ text: "행사 수정" }`, `{ text: "행사 취소" }`로 만들고, 선택 문자를 받으면 다음처럼 새 임시 링크를 답장한다.

```js
const modes = { "행사 등록": "create", "행사 수정": "edit", "행사 취소": "cancel" };
const selectedMode = modes[message?.text?.trim()];
if (message?.chat?.type === "private" && selectedMode && process.env.PUBLIC_URL) {
  const token = randomBytes(32).toString("hex");
  db.prepare("INSERT INTO tickets VALUES(?,?)").run(token, Date.now() + 3600000);
  await telegram("sendMessage", {
    chat_id: message.chat.id,
    text: `${message.text} 화면을 열어주세요. 링크는 1시간 동안 사용할 수 있습니다.`,
    reply_markup: {
      inline_keyboard: [[{
        text: `${message.text} 열기`,
        url: `${process.env.PUBLIC_URL}/?mode=${selectedMode}#${token}`,
      }]],
    },
  });
}
```

예전 링크의 `#token` 처리는 `public/app.js`에 유지한다.

## 이전 메시지 아래 버튼 코드

`server.js`의 `worker()` 안에서 `/start` 또는 `/menu`를 처리하던 코드다. 이전 형식으로 돌아가려면 현재 DM 키보드 처리 분기를 이 블록으로 교체하고 서버를 재시작한다.

```js
if (
  u.message?.text?.match(/^\/(start|menu)(@\w+)?(?:\s|$)/) &&
  process.env.PUBLIC_URL
) {
  const token = randomBytes(32).toString("hex");
  db.prepare("INSERT INTO tickets VALUES(?,?)").run(
    token,
    Date.now() + 3600000,
  );
  await telegram("sendMessage", {
    chat_id: u.message.chat.id,
    text: "행사 신청·수정·취소를 선택해주세요. 링크는 1시간 동안 사용할 수 있습니다.",
    reply_markup: {
      inline_keyboard: [
        [
          {
            text: "행사 신청",
            url: `${process.env.PUBLIC_URL}/?mode=create#${token}`,
          },
        ],
        [
          {
            text: "행사 수정",
            url: `${process.env.PUBLIC_URL}/?mode=edit#${token}`,
          },
          {
            text: "행사 취소",
            url: `${process.env.PUBLIC_URL}/?mode=cancel#${token}`,
          },
        ],
      ],
    },
  });
}
```

이전 코드는 버튼을 한 번 누르면 웹을 열지만, 메시지를 받은 뒤 1시간이 지나면 링크가 만료된다. `PUBLIC_URL`은 외부에서 접근 가능한 HTTPS 주소여야 한다. 기존 `tickets` 인증, 웹 화면, DB 코드는 그대로 사용할 수 있다.

이미 DM에 표시된 입력창 위 키보드를 없애려면 복원된 봇이 개인 대화에 `reply_markup: { remove_keyboard: true }` 메시지를 한 번 보내야 한다. 서버 코드만 교체해도 기존 키보드가 텔레그램 화면에 남을 수 있다.
